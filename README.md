## Running the Singleton pattern example

`Main.java` belongs to the `Singleton_Pattern` package. From the repository root, compile and run it using its fully qualified class name:

```powershell
javac Singleton_Pattern\Main.java
java Singleton_Pattern.Main
```

Running `java Main` from inside the `Singleton_Pattern` directory fails because the class is declared in a package.
